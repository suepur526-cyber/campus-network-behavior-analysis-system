# 数据库配置说明

系统默认使用 SQLite，便于开发、测试和答辩现场快速启动。真实部署时可通过环境变量切换到 MySQL。

## SQLite 默认配置

无需额外配置，直接运行：

```powershell
python run.py
```

数据库文件：

```text
campus_network.db
```

## MySQL 配置

先安装依赖：

```powershell
python -m pip install -r requirements.txt
```

创建数据库：

```sql
CREATE DATABASE campus_network CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

设置环境变量：

```powershell
$env:DATABASE_URL='mysql+pymysql://root:你的密码@127.0.0.1:3306/campus_network?charset=utf8mb4'
$env:SECRET_KEY='请替换为随机长字符串'
$env:FLASK_APP='run.py'
flask init-db
flask seed-data
flask detect-anomalies
python run.py
```

说明：

- `DATABASE_URL` 控制数据库连接。
- 没有设置 `DATABASE_URL` 时，系统自动使用 SQLite。
- 学校答辩现场如没有 MySQL 环境，使用 SQLite 更稳定；论文中可以说明系统已支持 MySQL 配置。
