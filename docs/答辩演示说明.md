# 基于 Python 的校园网用户行为分析系统答辩说明

## 一、演示准备

启动系统前执行：

```powershell
python -m pip install -r requirements.txt
$env:FLASK_APP='run.py'
flask init-db
flask seed-data
flask detect-anomalies
python run.py
```

访问地址：

```text
http://127.0.0.1:5000
```

自动化测试：

```powershell
python -m pytest -q
```

当前测试覆盖 17 个用例，包括日志解析、数据清洗、导入、查询、分页、CSV 导出、行为分析、异常检测、目录采集、系统状态和测试报告接口。

## 二、为什么使用验证日志

真实校园网日志涉及用户隐私、设备权限和学校网络安全管理要求，学生毕业设计不适合直接接入真实防火墙、路由器或代理服务器。

本系统使用验证日志文件进行验证。验证数据按照校园网典型访问场景构造，包含学生、教师、访客三类用户，覆盖学习平台、视频应用、社交应用、办公系统、DNS、HTTP/HTTPS、TCP/UDP 等常见行为，并刻意加入高频连接、异常大流量、端口扫描、可疑访问等异常场景。

因此，系统虽然不直接接入真实校园网设备，但完整验证了“数据接入、数据清洗、行为分析、异常检测、可视化展示、日志查询、测试评估”的业务闭环。

## 三、推荐演示流程

1. 打开“总览仪表盘”
   - 展示日志总量、用户数量、总流量、异常日志数量。
   - 展示流量趋势、协议分布、访问类别、近期告警、用户排行。

2. 打开“日志接入”
   - 点击导入验证数据源。
   - 说明系统支持 CSV、JSON、TXT/Syslog-like 三类日志。
   - 说明导入时会自动完成字段标准化、去重、时间格式统一和数值清洗。

3. 打开“日志查询”
   - 按用户、协议、异常状态筛选。
   - 演示分页按钮。
   - 点击“导出CSV”，说明可以导出当前筛选结果。

4. 打开“行为分析”
   - 说明系统从时间、流量、内容、群体四个维度分析用户行为。
   - 展示上网高峰、用户群体分布、应用分布和流量排行。

5. 打开“异常检测”
   - 点击“立即检测异常”。
   - 说明规则检测包括高频连接、异常大流量、端口扫描、可疑访问。
   - 说明机器学习检测使用 KMeans 聚类和 Isolation Forest。
   - 展示异常类型图和告警列表分页。

6. 打开“测试报告”
   - 演示“目录采集验证”按钮。
   - 展示系统运行状态、数据库记录数、最近导入时间、最近检测时间。
   - 展示准确率、精确率、召回率、F1 值、查询响应时间和测试用例列表。

## 四、答辩讲解重点

- 系统采用 B/S 架构，后端使用 Flask，数据库默认使用 SQLite，支持通过 `DATABASE_URL` 切换到 MySQL。
- 数据处理使用 Pandas 和 NumPy，适合日志清洗、字段标准化和统计分析。
- 异常检测使用“规则 + 机器学习”的组合方式，既能解释明显异常，也能识别偏离正常模式的行为。
- 可视化使用 ECharts，能够直观展示流量趋势、协议分布、访问类别和异常告警。
- 系统测试覆盖核心功能，能够证明系统不是静态页面，而是完整可运行的软件。

## 五、可作为论文展望的内容

- 接入真实防火墙、路由器、代理服务器日志。
- 使用 Filebeat 或 Rsyslog 实现真实实时采集。
- 数据库从 SQLite 迁移到 MySQL 或 PostgreSQL。
- 引入用户权限管理和审计日志。
- 使用 Spark Streaming 或 Flink 实现流式处理。
- 增加隐私脱敏和用户数据合规管理机制。
